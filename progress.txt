## Itération 3 — 2026-08-02 — Task #4 : Vue pipeline en timeline chronologique

- **Service frontend** `pipeline-timeline-service.ts` (+ 15 tests) : `nodeDurationMs`, `pipelineTotalDurationMs` (bornes du run sinon somme des durées connues), `formatDuration` ("45 s", "1 min 05 s", "2 h 12 min"), `sortTimelineNodes` (chronologique, étapes jamais exécutées en fin), `runTimeRange`, et vue persistée `loadPipelineViewMode`/`savePipelineViewMode` (`nodra.pipelines.view`, pattern `view-mode-service`).
- **Composant** `PipelineTimeline` dans `PipelineFlux.tsx` : timeline verticale chronologique style GitHub Actions — une rangée par étape (badge statut, titre cliquable → fiche mission, nodeKey · Agent/Humain, plage horaire, durée, chip "essai N" si tentative > 1, gate manuelle), triée par début de run, + pied de page (X/N étapes exécutées, durée totale, début/fin du run).
- **Toggle Graph / Timeline** dans la tête de la carte pipeline (`PipelineCard`), persistant entre rechargements ; les actions Démarrer/Avancer restent disponibles dans les deux vues.
